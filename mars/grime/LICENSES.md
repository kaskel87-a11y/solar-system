# Grime pass: asset credits

Everything in the grime pass is made in code at runtime. No image, model or audio files are shipped.

| Asset | Where | Source / license |
|---|---|---|
| Wall grime atlas (soot, rust, water stains, cracks, burns, drips) | `mars/grime-tex.js` | Procedural canvas, self-made, CC0 |
| Graffiti, tags, stencils, posters (all made-up crews/brands) | `mars/grime-tex.js` | Procedural canvas, self-made, CC0 |
| Ground atlas (oil, puddles, litter, glass) | `mars/grime-tex.js` | Procedural canvas, self-made, CC0 |
| Corrugated metal, fabric, cart wire, rust metal, soot, puff, flame, glow, concrete | `mars/grime-tex.js` | Procedural canvas, self-made, CC0 |
| Neon signs (LIQUOR, PAWN & GUNS, HOTEL ARES, ORGANS BOUGHT… all fictional) | `mars/grime-tex.js`, `mars/grime.js` | Procedural canvas, self-made, CC0 |
| Barks, pirate radio script | `mars/grime-lines.js` | Written for this game, CC0 |
| PIRATE 66.6 sludge beat | `mars/grime-lines.js` (drives the existing mars-audio synth) | Procedural, self-made, CC0 |
| Street people, camps, tents, carts | `mars/grime-street.js` | Built from Three.js primitives, self-made, CC0 |

Fonts are the system UI font. No real brands, people or places are used.
